# Busan Care Bridge · 거래서류 생성기

리쥬란/시바산(BCB) B2B 수출용 견적서·인보이스·패킹리스트 생성 도구입니다.
관리자(본인) 전용 도구이며, 모든 데이터는 브라우저(localStorage)에만 저장되고
이 저장소 코드에는 저장되지 않습니다.

## 사용 방법
- GitHub Pages 링크로 접속해서 바로 사용
- 또는 `index.html` 파일을 다운로드해서 더블클릭으로 로컬 실행

## 배포(GitHub Pages)
Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/(root)` 선택 후 저장.
몇 분 후 `https://<사용자명>.github.io/<저장소명>/` 에서 접속 가능합니다.
